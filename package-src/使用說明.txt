 OpenHES 智慧電表監控平台 — 「系統總覽」展示 Demo
============================================================

■ 最簡單的開啟方式（推薦給一般使用者）
------------------------------------------------------------
  直接「雙擊」本資料夾中的：

        開啟Demo（請雙擊我）.html

  即可在瀏覽器中開啟整個 Demo。
  ‧ 完全離線，不需網路、不需安裝任何軟體
  ‧ 建議使用 Google Chrome 或 Microsoft Edge 瀏覽器


■ 操作說明
------------------------------------------------------------
  ‧ 上方 KPI 卡片（連線率 / LP / 午夜 / ALT）可點選，
    會連動下方的圖表與地圖著色。
  ‧ 滑鼠移到 LP / 午夜 / ALT / 事件數量 卡片上，
    會顯示該數值的「計算依據」。
  ‧ 地圖可三層往下查看：
        全台縣市  →  鄉鎮市區  →  村里
    直接點地圖上的區域即可往下鑽。
  ‧ 點左上角「← 返回」或上方麵包屑文字，可回到上一層。
  ‧ 進入「村里」層後，點任一區，右側會滑出該區的電表清單。
  ‧ 左上角的選單圖示，可收合／展開左側功能欄。
  ‧ 右側「連線率 × 讀表率比對」散布圖，紅點代表
    「連得上卻讀不到」的重點查核區域。


■ 進階：放到公司內網或網站
------------------------------------------------------------
  若需要架設在內網或網站伺服器，請打開：
        進階_內網部署  資料夾
  內有「內網部署說明.txt」與一鍵啟動工具。


■ 重要說明
------------------------------------------------------------
  本版本為「展示用途」，畫面上的數據為「模擬資料」，
  並非真實電表數據，亦未連接任何後端系統。
