 OpenHES Demo — 內網 / 網站 部署說明
============================================================

本應用是「純前端靜態網站」（HTML / CSS / JavaScript），
不需要後端伺服器、不需要資料庫，所有資料皆為內建模擬資料。


■ 方式 A：架在靜態網站伺服器（正式內網建議）
------------------------------------------------------------
  將 web 資料夾內的「所有檔案」上傳到您的網站空間，
  以「網站根目錄」方式提供即可。

  支援任何靜態主機：
    ‧ IIS（Windows Server）
    ‧ Nginx / Apache
    ‧ 任何雲端靜態空間 / 物件儲存

  IIS 範例：
    1. 把 web 資料夾內容複製到網站實體路徑
       （例如 C:\inetpub\wwwroot\openhes-demo）
    2. 在 IIS 建立網站或應用程式，指向該路徑
    3. 預設文件設定 index.html
    4. 用瀏覽器開啟該網站網址即可

  Nginx 範例設定：
    server {
      listen 80;
      root /var/www/openhes-demo;   # = web 資料夾內容
      index index.html;
    }


■ 方式 B：Windows 本機快速預覽（免安裝、免架站）
------------------------------------------------------------
  雙擊「啟動本機伺服器.bat」。
  它會用 Windows 內建的 PowerShell 起一個本機網站，
  並自動開啟瀏覽器（網址類似 http://localhost:8080/）。

  ‧ 關閉那個黑色視窗，即停止服務。
  ‧ 若因權限無法啟動，請改用最簡單的方式：
    回上一層，直接雙擊「開啟Demo（請雙擊我）.html」。


■ 技術備註
------------------------------------------------------------
  ‧ 本網站為單頁應用（SPA），無需特殊路由設定。
  ‧ 無任何外部 API 連線，可在完全離線的內網環境運行。
  ‧ 內含台灣縣市 / 鄉鎮市區 / 村里界線圖資（已簡化）。
